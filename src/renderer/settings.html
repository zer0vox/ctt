Claude plan limits

Live updates recommended

Uses the Claude login that Claude Code saved on this computer to make the same read-only request Claude Code makes for /usage. Works with the VS Code panel, the terminal, JetBrains and the desktop app, and includes claude.ai usage. Your login is only sent to api.anthropic.com and is never stored by Token Pup. Unofficial: it could stop working if Anthropic changes it.

Without live updates

Token Pup also reads the copy of your usage that Claude Code keeps, which refreshes only when Claude Code checks usage (for example /usage). If you run claude in a terminal on a Pro or Max plan, the status line bridge updates after every reply and shows 5h 42% · 7d 18%.

Edits ~/.claude/settings.json (a backup is saved next to it). An existing status line command keeps working. Needs Node.js on your PATH.

Claude Code logs

Only token counts and timestamps are read, never your prompts. Costs are estimates at API list prices.

Anthropic API credits

Needs an Admin API key (sk-ant-admin…) from the Claude Console. It is encrypted with Windows DPAPI and only sent to api.anthropic.com.

The API has no balance endpoint. Enter the balance from Console › Billing and the date you read it; Token Pup subtracts spend since then. A balance takes priority over a monthly budget.
